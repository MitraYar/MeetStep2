# MeetStep — SMK 37 Pro standalone, Windows x64

8 patterns, each containing 9 independent MIDI channels, 128 notes and up to 64 steps.
Each pattern has a playback length of 1–64. Shortening retains hidden step data.
See [Russian control reference](docs/controls-ru.md) for the complete keyboard map.
The editor displays 16 notes × 16 steps. C1 is MIDI note 36. Notes from SMK MIDI
channels 1–9 select both the track and note when Q (Follow MIDI keys) is enabled.
C1 is at the bottom of the initial range. Playback emits on those same channels.
MIDI Clock is 24 PPQN, 30–300 BPM. Audio is generated by your receiving instrument.

## Controls

- Space: play/stop. Stop releases sequence/drone notes and resets to the start.
- Num 1–8 queues a pattern at the end of the playing pattern. Double-tap the same
  key within 400 ms to switch immediately. Alt + Num 1–9 toggles instrument mutes.
  Ctrl + Num 1–9 clears that instrument in the viewed pattern; double-tap the same
  combination within 400 ms to clear the whole viewed pattern. These edits are undoable.
- Ctrl + physical `/` (Russian `.`): Options. Z / Я: Undo; X / Ч: Redo.
- Left/right arrows: select one of 8 groups of 8 steps; the visible 16-step page follows.
- Ctrl + left/right arrows selects a 16-step page. Ctrl + J/L shifts only the visible
  grid by one step, allowing selection across page boundaries without changing pads
  or knob groups. Arrows, Home/End and H/semicolon reset this visual shift.
- Up/down arrows move the visible note range by 16. I/J/K/L move the cell cursor.
- Ctrl + I/K shifts the range by one, independently for each MIDI channel.
  Navigation uses the operating system's keyboard repeat rate. Home/End moves to
  the first/last playable step. Q toggles MIDI-key following; W toggles playhead following.
- H / semicolon wrap through the four 16-step pages; Y / P move encoder groups.
- Shift + I/J or Shift + left drag selects a rectangle. Ctrl + click toggles individual
  selected cells. Shift + right drag erases a rectangle on release, with one Undo.
- Shift + S toggles Select Mode: left drag selects; a single click or right click
  clears selection without leaving the mode. Hold a note header for 0.5 s to select
  all 64 cells in its row. Subsequent Ctrl/Shift header selections need no hold.
  Delete/Backspace clears selected cells, or the cursor note if nothing is selected;
  T inserts only selected empty cells.
- A toggles note/whole-step scope on the current channel. S toggles whole-step
  scope on the current/all channels, leaving note mode.
- Ctrl + 1…0 duplicates 1…10 consecutive source steps at the cursor immediately
  after that block. Ctrl + Shift + 1…0 copies them to the last N steps of the current
  playback length. Copies are snapshots (overlap-safe) and select the destination.
  Out-of-range operations are clipped; an operation past the last step does nothing.
- Ctrl + D duplicates the selected rectangle. Its cursor is the first (upper-left)
  cell. Ctrl + Alt + 1…0 copies N steps to the left, truncating anything before step 1.
  F (Fill N) repeats ordinary duplication to the pattern end. Undo/Redo restores the edit's
  pattern, channel, cursor, view and selection.
- D mirrors future mouse/pad step writes and erases across all four 16-step pages.
  Disable it before detailing individual pages. It does not overwrite other pages
  merely by being enabled.
- Physical slash (VK_BF) toggles live audition of keyboard MIDI channels 1–9;
  selection and sequencer playback continue when audition is off. G is Gate View.
- Alt + top-row 1–9 selects a channel. Ctrl + B (Hotkey Mode) routes keyboard input
  to that channel regardless of the incoming channel; note-offs retain their original route.
- Shift + Num 1–8 copies the current channel to a pattern; double-tap copies the
  whole pattern and its length. Alt + Shift + Num 1–8 copies the selected note.
  Copying and clearing preserve the viewed pattern/channel.
- Hold Alt and press F1…F6 for tens 10…60, or F7 for zero tens, then a digit for
  units. Alt+F2 then 6 sets 26 steps; Alt+F7 then 8 sets 8. Values 0 and 65–69
  are rejected. Releasing Alt cancels a pending entry. GUI Length changes the same value.
- E edits velocity on existing notes; R edits gate. Left drag stays locked to the
  initial row: above it raises values, below lowers, within the row preserves the
  original value. Right drag paints the insertion/fader value. These modes never add
  notes. While left mouse is held, changes from faders 1/2 write absolute values.
  Gate is 15–300%; labels appear for one second after editing. Short gates use an
  interior trapezoid, with its top-right at gate% and bottom-right at gate% + 6%.
  Gates ≥100% use a full rectangle. Velocity mouse travel is three times shorter;
  Interface → Velocity mouse sensitivity adjusts the multiplier (1 = previous feel).
  Mouse Back/Forward buttons have no editing function.
- Left drag sets steps, right drag erases, locked to the starting row. A complete
  gesture is one Undo. Existing cells keep their velocity/gate unless a paint mode
  is enabled or a fader edits the cursor cell. Context changes cancel the gesture.
- Clear note / Clear channel / Clear pattern: selected note, current track, or
  all 9 tracks in the viewed pattern. All are undoable.
- Pattern buttons change the view and queue playback for the current cycle's end;
  enable View only to browse independently. Nine mute buttons accept left drag to
  mute and right drag to unmute. Muting never disables keyboard audition.
  The separate MUTES square mutes all on left click, unmutes all on right click;
  it does not participate in drag gestures.

The custom keyboard handler runs before Tk button bindings, preventing Space from
activating a focused Options button. Bindings use Windows physical virtual-key codes,
not typed characters. Text fields accept normal typing. Click a shortcut field to
record a physical key combination; Backspace clears it. Ctrl, Shift and Alt are supported.

## SMK pads

Bank 1 physical order: `40 41 42 43 48 49 50 51 / 36 37 38 39 44 45 46 47`.
Bank 2 adds 16 to each number. Positive Note On triggers actions; Note Off and
zero-velocity Note On release held modifiers without triggering actions.

| MIDI channel | Bank 1 | Bank 2 |
| --- | --- | --- |
| 10 | Tap toggles a step; hold ≥0.5 s selects without toggling | Pad 9 Play/Stop; 16 Undo; 8 Redo; pads 14/15 move groups left/right |
| 11 | Top row queues patterns 1–8; pad 16 Undo / hold 1 s Redo | Pad 9 Play/Stop; tap 16 Undo, hold 16 for 1 second Redo; pad 8 has no action |
| 12 | Pads 1–9 mute instruments 1–9 | Pad 9 Play/Stop; pad 16 Undo / hold 1 s Redo |
| 14–16 | Forward to the dedicated output | Forward to the dedicated output |

Channel 13 is no longer used. The undo hold performs only Redo, without an initial Undo.

Channel 11 bank 1 lower-row modifiers, held while pressing the destination in the
top row: pad 9 views without changing playback; pad 10 copies the current channel;
pad 11 copies only the selected note (64 steps). Copy overwrites the destination's
corresponding data, is undoable, and does not change the playing/viewed pattern.
Pad 12 clears the target pattern; pad 13 clears the selected note on the current
channel in the target pattern. Delete takes precedence, then note copy, channel copy,
and view. Multiple held step pads select multiple cells for fader scaling.
Holding an already selected step again deselects it.

## Mono, step input and recording

M toggles Mono per MIDI channel. Enabling it reduces existing chords in all patterns
to the selected note where present, otherwise the lowest note; Undo restores them.
New edits enforce one note per step. All pitches appear on the SMK step pads and
can be edited by the corresponding knobs. Hold or select a step and play a key to
transpose it with velocity, gate, articulation, approach and microtone intact.
Choosing a keyboard note then tapping a pad inserts/replaces that step without
jumping the chosen pitch to the previous note on that step.

Shift + K enables step input, with no automatic advance. J/L moves manually and
inserts all still-held MIDI notes on the destination step, even after minutes of
holding the chord. Note Off removes a key from this repeat set. A fresh chord after
releasing all keys replaces the current step. Shift + L enables Sticky input:
separate handfuls add to the existing chord instead of replacing it.
These bindings replace the former Shift + K/L selection commands.

Shift + R records keyboard onsets during playback, quantized to the nearest step,
including Swing timing. Within each channel, the first onset in a quantized step
stays there; a second moves one step right (wrapping at the pattern end); a third
replaces the middle onset. This applies to any pitches, not only repeated notes.
Only the current pass's small collision table is retained and is cleared at the next
pass. Recording writes the playing pattern even while viewing another pattern.

## Drone, articulation and pitch

V toggles drone entry: MIDI keys toggle drones in the viewed pattern/channel.
In this mode, left clicking a note header enables its drone; right clicking disables it.
Drones sound only while transport runs; identical drones in consecutive patterns
continue without retriggering. Stop releases them; right click a row header/cell to
remove its drone. B and N are persistent legato/non-legato entry brushes. Their
status belongs to each grid cell; drones belong to whole note rows. C (Cancel)
clears articulation when clicking a cell or holding its pad; press C again to turn
the brush off. Turning B/N off does not enable Cancel. Legato holds until the next onset/chord with
2 ms overlap and ties identical pitches. Non-legato leaves a 1/128-whole-note gap
before the next onset and retriggers repeated pitches. Cells on the same row may
use different articulation. Entry does not disable the brush. Default uses gate.

Top-row keys 1/2 add a slow/fast approach from above; 3/4 from below. Their random
amplitude is 25–35 cents, duration 1/16 or 1/48 whole note ±30 ms. Keys 5/6/7/8
set −68/+22/−22/−50 cents. Microtone and approach combine independently, per
MIDI channel. Keys/buttons immediately apply their component to selected notes;
backtick clears selected and pending pitch while preserving articulation.
Without a selection, the next mouse/pad insertion consumes the pending preset.
Hold one key from 1–4 and/or 5–8 to apply the combination to every note entered
while held. Shift + backtick toggles Set pitch: a persistent paint-only brush for
existing notes, without inserting new ones. Hold backtick and left-drag to clear
pitch on existing notes. Until insertion, presets also affect live audition.
Minus hides approach arrows, equals hides microtone labels.
The Pitch buttons expose the same modes. Options → Microtones / Approaches edits
microtone cents and transition time from the current pitch (ms), approach start,
random ± cents, time (`1/16`, `1\128`, or plain milliseconds), and envelope curvature
(0 concave, 50 linear, 100 convex). New presets use these settings; existing cells
retain their stored sound. Approach timing retains its ±30 ms variation.

Ctrl + backtick (Disable modifiers) turns off Q/W/E/R/F, Select Mode, Drone,
articulation brushes, current-channel Mono, Step/Sticky/Record and Set pitch,
and clears pending pitch. It preserves Gate View, Audition, D, Hotkey Mode and playback.

Pitch uses standard MIDI pitch bend with an RPN range of ±2 semitones. All sounding
notes on a channel share one bend; a sequencer chord uses its lowest note's preset.
The SMK pitch wheel arriving on channel 1 routes only to channels with held audition
notes and adds to their pitch preset. Use an instrument that honors pitch-bend RPN.

## Encoders

SMK channel 6: bank 1 CC48–55 edits velocity; bank 2 CC56–63 edits gate. All eight
knobs edit the selected group of eight steps. Empty cells stay empty. The former
Global knobs mode has been removed. GUI knob mode can be pinned to velocity or
gate regardless of the hardware bank; Reset knobs restores bank interpretation and
takeover. Each knob is listed in Shortcuts and can be remapped with MIDI Learn.
The status line reports incoming MIDI CC/channel and takeover state.

Faders on channel 1: CC64 velocity, CC65 gate, CC66 Swing, CC67 BPM (bank 2: 68–71).
Without a selection, faders 1/2 edit the cursor note if present and update insertion
values. With a Ctrl/Shift/duplication selection they scale a fixed snapshot, with
1× initially and up to 2×; repeated values never compound the scale.
Values clamp to velocity 1–127 and gate 15–300%. Scaling only changes explicitly
selected cells; A/S controls copying and does not expand this selection.
Swing ranges from straight sixteenths to a 2:1 triplet
ratio; MIDI Clock stays straight at 24 PPQN. Pin faders 1–4 restores and saves
the standard MIDI assignments. MIDI Panic stops transport and releases live/sequence
notes, sends All Notes Off / All Sound Off, clears pending input and resets pickup.

All knobs and faders use Scale takeover. The first CC anchors the physical
position; further movement immediately scales the remaining travel towards the
corresponding value endpoint, without waiting to cross the stored value. Context
changes re-anchor the control. With left mouse held, faders 1/2 use absolute input.

CC30 at velocity60 maps proportionally to velocity1 at CC0 and velocity127 at CC127.
When fewer than three CC counts remain toward an endpoint, a ten-count reserve
prevents a one-count jump. Move back into the range then toward the endpoint to
reach it in this case. Fractional motion accumulates before rounding, so fine turns
continue to work. Direction changes start a new proportional segment.
This is absolute-CC mode; relative encoder protocols are not supported yet.

## Interface and MIDI options

Options has MIDI, Shortcuts, Interface, Microtones / Approaches and Channel outputs tabs, with Apply/Close, and remembers the
last selected tab during the session. Close discards unapplied changes. All keyboard,
GUI and pad actions are listed in Shortcuts with physical VK code, readable Latin key,
controller alias and MIDI Learn. Interface provides Dark, Light and Legacy light
themes and separate channel 10–16 / bank 1–2 color tabs:

- Ch10 bank 1 empty colors repeat in a cycle of length 1–7 across all 64 steps,
  without restarting at page boundaries; default black.
  Enabled steps use a linear RGB gradient between velocity 0 and 127 colors.
- Ch11 bank 1 top row uses one color at repeating 100%, 65%, 35% brightness;
  lower utility pads have independent colors.
- Other bank 1 pads and every bank 2 have independently editable colors.
  Functional/bound pads show a star and an action tooltip.

The PC empty-grid tint slider controls only the GUI background (0–100%, default 8%).
Hardware colors and enabled-note colors retain their intensity. Channel changes repaint the
shared pad memory when the first event arrives; use Pad layout in the GUI to repaint
without pressing a pad. RGB protocol details and verification are in `docs/protocol.md`.

Configure two MIDI inputs, notes/clock output, optional script output, SMK RGB
output, and the dedicated output for pads on channels 14–16. Forwarded note-offs
are retained across mapping changes and released on Panic/disconnect. The script
output is reserved (no scripting engine yet). Settings live in `~/.meetstep.json`
and can be exported/imported as `.settingsjson` from Options. Projects use
`.patternsjson`: all 8 patterns, lengths, BPM, drones, articulation, stored pitch,
mutes, Swing, Mono and per-channel note ranges. Version 4 row articulation migrates
to per-cell articulation. Old 16-step files import
into pattern 1, channel 1, length 16, with 48 empty steps appended. User-edited MIDI bindings
are retained during config migration; old stock Space/transport bindings are updated.

Channel outputs can route channels 1–9 to separate MIDI devices for DAWs without
channel filtering. Channel 1 and Clock/Start/Stop use the main Sequence / audition
output; channels 2–9 have optional device overrides (empty = main output).
Channel numbers remain unchanged. Notes, audition, drones, pitch bend and RPN use
the same route. Shared device names open only one handle; clock is sent only once.

Device checks and reconnects run off the UI thread every two seconds. Missing or
failed ports reconnect independently. An idle input refreshes after 120 seconds
without messages or held keys; output playback continues. Reopened outputs restore
active voices and the main transport position. Reconnect MIDI stops transport and
reopens all configured ports manually. Unexpected UI exceptions are logged to
`~/.meetstep.log` without terminating MIDI polling. Continuous CC bursts are
coalesced while preserving anchors, direction reversals and note event order.
MIDI dispatch yields to the UI after an 8 ms budget.

## Run / build

Install Python 3.12 x64 on Windows, then run:

```powershell
powershell -File build-windows.ps1
```

Result: `dist/MeetStep.exe`; Python is bundled. The GitHub Actions Windows workflow
runs the tests (including real Tk focus/shortcut tests) before packaging. For source
development: create `.venv`, install `requirements.txt`, run `python app.py`.
Tests: `python -m unittest discover -s tests -v`.
CPU comparison and the reproducible benchmark are in [docs/performance.md](docs/performance.md).

Timing uses a Python worker thread and is not a hard real-time guarantee. Hardware
MIDI/LED behavior must be verified with the SMK; CI tests use simulated MIDI events.
