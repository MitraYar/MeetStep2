# Управление MeetStep

Клавиши привязаны к физическим позициям, работают и в русской раскладке.

| Клавиши | Действие |
| --- | --- |
| Пробел | Play / Pause |
| Ctrl + / | Настройки |
| Z / X | Undo / Redo |
| J / K / L / I | Курсор влево / вниз / вправо / вверх |
| Shift + J/K/L/I | Расширить прямоугольное выделение |
| H / ; | Предыдущие / следующие 16 шагов, циклически |
| Y / P или ← / → | Группа нобов на 8 шагов влево / вправо |
| ↑ / ↓ | Диапазон нот на 16 вверх / вниз |
| . | Прослушивание клавиш MIDI 1–9: вкл/выкл |
| A | Нота ↔ целый шаг на текущем канале |
| S | Целый шаг: текущий ↔ все каналы; режим ноты отключается |
| Ctrl + 1…0 | Копировать 1…10 шагов от курсора сразу за исходным блоком |
| Ctrl + Shift + 1…0 | Копировать 1…10 шагов от курсора в последние N шагов паттерна |
| D | Запись/стирание шагов сразу на четырёх страницах: вкл/выкл |
| G | Показ gate в процентах ↔ velocity |
| Alt + F1…F6, затем цифра | Десятки 10…60 + единицы, Alt удерживать |
| Alt + F7, затем цифра | Десятки 0 + единицы, Alt удерживать |

Длина паттерна 1–64. Alt + F2 → 6 = 26 шагов; Alt + F7 → 8 = 8 шагов.
При сокращении длины данные последующих шагов сохраняются. На сетке они приглушены.

ЛКМ рисует, ПКМ стирает с фиксацией на исходной ноте. Shift + ЛКМ выделяет
прямоугольник; Ctrl + ЛКМ добавляет/убирает отдельные ячейки. Shift + ПКМ стирает
прямоугольник при отпускании. Боковая кнопка «назад» меняет velocity, «вперёд» —
gate. Удерживая её, двигайте мышь выше/ниже исходного ряда; соседние ряды не меняются.

Нобы: банк 1 — velocity, банк 2 — gate; восемь нобов соответствуют восьми шагам.
Фейдеры: 1 — velocity, 2 — gate, 4 — BPM. При выделении фейдеры 1/2 масштабируют
выбранные данные; середина соответствует 1×, верх — 2×. A/S определяют охват.
Gate всегда ограничен 15–300%. Для предотвращения скачков сначала подведите
фейдер к текущему значению (для масштабирования — к середине).

Если крутить быстро в сторону от сохранённого значения более 0,3 с, контрол
начинает менять значение в направлении вращения. Reset knobs возвращает режим
по банкам; список рядом позволяет принудительно выбрать velocity или gate.
Pin faders 1/2/4 восстанавливает назначения фейдеров. MIDI Panic гасит ноты и
сбрасывает состояние MIDI-контролов.

Канал 10, банк 2: пэд 9 — Play/Pause, 16 — Undo, 8 — Redo; нижние пэды 6/7
(общие номера 14/15) — предыдущие/следующие 8 шагов. Канал 11, банк 2:
пэд 9 — Play/Pause; короткое нажатие 16 — Undo, удержание 1 с — Redo.
Канал 13 не используется. Управление выбором/просмотром/копированием паттернов
в первом банке канала 11 сохранено.

Цветовой цикл пустых шагов непрерывен на всех 64 шагах. Ползунок PC empty-grid tint
во вкладке Interface меняет только слабую подкраску сетки на ПК; по умолчанию 8%.
