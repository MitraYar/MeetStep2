# Управление MeetStep

Клавиши привязаны к физическим позициям, работают и в русской раскладке.

| Клавиши | Действие |
| --- | --- |
| Пробел | Play / Stop со сбросом позиции |
| Ctrl + / | Настройки |
| Z / X | Undo / Redo |
| Num 1…8 | Переключить паттерн после конца цикла; двойное нажатие — сразу |
| Alt + Num 1…9 | Мьют соответствующего инструмента |
| Ctrl + Num 1…9 | Очистить инструмент в просматриваемом паттерне |
| Ctrl + та же Num дважды | Очистить весь просматриваемый паттерн |
| J / K / L / I | Курсор влево / вниз / вправо / вверх |
| Shift + J/I | Расширить прямоугольное выделение |
| Shift + S | Select Mode: обычное протягивание ЛКМ выделяет |
| Delete / Backspace | Очистить выделенные ячейки; без выделения — ноту под курсором |
| T | Ввести ноты в выделенные пустые ячейки |
| Alt + 1…9 | Выбрать канал (цифры верхнего ряда) |
| Ctrl + B | Hotkey Mode: MIDI-клавиши используют выбранный с ПК канал |
| Shift + Num 1…8 | Копировать текущий канал в паттерн; двойное нажатие — весь паттерн |
| Alt + Shift + Num 1…8 | Копировать выбранную ноту в паттерн |
| Shift + K | Степ-инпут с ручным продвижением J/L и повтором удерживаемого аккорда |
| Shift + L | Sticky степ-инпут: добавлять ноты несколькими отдельными нажатиями |
| Shift + R | Запись с клавиш при воспроизведении |
| H / ; | Предыдущие / следующие 16 шагов, циклически |
| Ctrl + ← / → | Предыдущая / следующая страница из 16 шагов |
| Ctrl + J / L | Только визуально сдвинуть сетку на один шаг; пэды и нобы остаются на прежних группах |
| Y / P или ← / → | Группа нобов на 8 шагов влево / вправо |
| ↑ / ↓ | Диапазон нот на 16 вверх / вниз |
| Ctrl + I / K | Смещение диапазона на одну ноту, отдельно для каждого канала |
| Home / End | Курсор в начало / конец паттерна |
| Q | Следование диапазона и курсора за MIDI-клавишами |
| W | Следование страницы за плейхедом |
| / (VK_BF) | Audition: прослушивание клавиш MIDI 1–9 |
| A | Нота ↔ целый шаг на текущем канале |
| S | Целый шаг: текущий ↔ все каналы; режим ноты отключается |
| Ctrl + 1…0 | Копировать 1…10 шагов от курсора сразу за исходным блоком |
| Ctrl + Shift + 1…0 | Копировать 1…10 шагов от курсора в последние N шагов паттерна |
| Ctrl + Alt + 1…0 | Копировать N шагов от курсора влево; выходящее за шаг 1 обрезается |
| Ctrl + D | Дублировать выделенную группу |
| F | Fill N: повторять дублирование до конца паттерна |
| D | Запись/стирание шагов сразу на четырёх страницах: вкл/выкл |
| G | Gate View: показ gate в процентах ↔ velocity |
| E / R | Протягиванием менять velocity / gate существующих нот без добавления новых |
| V | Ввод дронов: MIDI-клавиша включает/выключает дрон |
| B / N | Постоянный режим ввода ячеек легато / нон-легато |
| C | Cancel: при клике по ячейке или удержании её пэда убрать легато/нон-легато |
| M | Моно для текущего канала |
| 1 / 2 | Подъезд сверху: медленный / быстрый |
| 3 / 4 | Подъезд снизу: медленный / быстрый |
| 5 / 6 / 7 / 8 | Микротон −68 / +22 / −22 / −50 центов |
| Клавиша слева от 1 (backtick) | Сброс микротонов/подъездов выделения и ожидающего пресета; удерживать + ЛКМ — кисть сброса |
| Shift + backtick (VK_C0) | Set pitch: постоянная кисть модификаторов по существующим нотам, без добавления новых |
| Ctrl + backtick | Disable modifiers: выключить режимы ввода, включая запись |
| − / = | Скрыть/показать стрелки подъездов / числа микротонов |
| Alt + F1…F6, затем цифра | Десятки 10…60 + единицы, Alt удерживать |
| Alt + F7, затем цифра | Десятки 0 + единицы, Alt удерживать |

Длина паттерна 1–64. Alt + F2 → 6 = 26 шагов; Alt + F7 → 8 = 8 шагов.
При сокращении длины данные последующих шагов сохраняются. На сетке они приглушены.
Двойное нажатие Num или Ctrl + Num распознаётся в пределах 400 мс.
Num — цифровой блок клавиатуры с включённым Num Lock. Очистку можно отменить Z.
Одиночный Undo после двойной очистки возвращает остальные каналы; второй — первый очищенный.
Копирование не переключает паттерн или канал. Очистка сохраняет выбранный канал.

ЛКМ рисует, ПКМ стирает с фиксацией на исходной ноте. Shift + ЛКМ выделяет
прямоугольник; Ctrl + ЛКМ добавляет/убирает отдельные ячейки. Shift + ПКМ стирает
прямоугольник при отпускании. Курсор выделения находится в верхней левой ячейке.
Undo/Redo возвращает канал, паттерн, курсор и выделение операции.
В Select Mode обычный ЛКМ выделяет прямоугольник. Одиночный клик и ПКМ снимают
выделение, оставляя режим включённым. Удержание заголовка ноты слева 0,5 с выделяет
все 64 шага ряда. Последующие выделения с Ctrl/Shift выполняются без ожидания.
Боковые кнопки мыши не используются. Обычный ЛКМ по существующей ноте сохраняет
её velocity/gate. В E/R ЛКМ меняет только существующие ноты: выше исходного ряда
увеличивает значения, ниже уменьшает, на уровне ряда сохраняет их. ПКМ записывает
значение фейдера. При зажатой ЛКМ изменения фейдеров 1/2 записываются абсолютно.
Для velocity движение по умолчанию втрое короче прежнего. Interface → Velocity mouse
sensitivity меняет множитель 0,1–10; 1 возвращает прежнюю чувствительность, 3 — новая
настройка. Gate сохраняет прежнюю чувствительность. Gate 15–99% дополнительно
показан трапецией внутри ячейки, от 100% — полным прямоугольником.
Визуальный сдвиг Ctrl + J/L позволяет выделять через границу страниц. ←/→,
Home/End, H/; и Ctrl + ←/→ сбрасывают его; MIDI-пэды и нобы не сдвигаются.

Нобы: банк 1 — velocity, банк 2 — gate; восемь нобов соответствуют восьми шагам.
Фейдеры: 1 — velocity, 2 — gate, 3 — Swing, 4 — BPM. При выделении фейдеры 1/2
масштабируют только явно выделенные ячейки от 1×, максимум 2×. A/S определяют
охват копирования и больше не расширяют выделение при скейлинге.
Gate всегда ограничен 15–300%. Все нобы и фейдеры используют Scale: первое
сообщение запоминает физическую позицию, следующие движения сразу изменяют текущее
значение, а оставшийся ход доводит его до границы. Пересекать старое значение не нужно.
Например, CC30 при velocity60: движение к CC0 пропорционально доводит velocity
до 1, к CC127 — до 127. Если до физической границы меньше трёх значений CC,
расчёт использует запас хода 10 CC, чтобы один отсчёт не вызывал скачок. Чтобы
дойти до границы в такой ситуации, отведите контрол внутрь диапазона и поверните
обратно. Дробные изменения накапливаются без потери при округлении.
Swing: от ровных шестнадцатых до отношения 2:1; MIDI Clock остаётся ровным.

Reset knobs возвращает режим
по банкам; список рядом позволяет принудительно выбрать velocity или gate.
Pin faders 1–4 восстанавливает назначения фейдеров. MIDI Panic гасит ноты и
сбрасывает состояние MIDI-контролов.

Канал 10, банк 1: короткое нажатие переключает шаг; удержание от 0,5 с выделяет
его без переключения. Повторное удержание снимает выделение. Можно зажать несколько
пэдов для масштабирования. В Mono пады показывают все ноты: зажатый шаг можно
перенастроить MIDI-клавишей с сохранением velocity/gate, артикуляции и pitch-модификаторов.
Это также работает для уже выделенных шагов после отпускания пэда. Либо сначала
выбирается клавиша, затем пэд добавляет её или заменяет другую высоту на своём шаге,
сохраняя выбранную для ввода ноту. В одном шаге остаётся одна нота. При включении Mono
из старых аккордов остаётся выбранная нота, а если её нет — самая нижняя; Undo доступен.
Канал 10, банк 2: пэд 9 — Play/Stop, 16 — Undo, 8 — Redo; нижние пэды 6/7
(общие номера 14/15) — предыдущие/следующие 8 шагов. Канал 11, банк 2:
пэд 9 — Play/Stop; короткое нажатие 16 — Undo, удержание 1 с — Redo.
Канал 11, банк 1: верхний ряд выбирает паттерн; удержание нижних пэдов 1/2/3/4/5
при выборе верхнего означает просмотр / копию канала / копию ноты / очистку паттерна /
очистку ноты. Пэд 16 — Undo, удержание 1 с — Redo.
Канал 12, банк 1: пэды 1–9 — мьюты инструментов. Мьюты не отключают прослушивание
клавиш. В GUI их можно протягивать: ЛКМ мьютит, ПКМ снимает мьют.
Отдельный квадратик MUTES: ЛКМ мьютит все, ПКМ снимает все мьюты. Он отделён
зазором и не участвует в протягивании. Тултип у полосы мьютов убран.
Канал 13 не используется. Каналы 14–16 передаются в отдельный Pads 14–16 output.

Дроны звучат только при запущенном транспорте; Stop их гасит. При смене паттерна
одинаковый дрон продолжается. Легато держит ноты до следующей ноты/аккорда с
нахлёстом 2 мс и связывает одинаковые высоты. Нон-легато отпускает за 1/128 целой
ноты до следующего вступления и заново атакует одинаковые высоты.
Легато/нон-легато — свойства каждой ячейки, а режим ввода B/N остаётся включённым
после ввода. C включает кисть отмены этих свойств. Дрон — свойство всего ряда;
его можно убрать ПКМ по ячейке или заголовку ноты. При включённом Drone ЛКМ по
заголовку включает дрон. Повторное C выключает Cancel; выключение B/N больше не
возвращает кисть Cancel.

Степ-инпут не двигает курсор по таймеру. J/L перемещает его вручную и вводит на
новом шаге все MIDI-клавиши, для которых ещё не пришёл Note Off: их можно держать
сколь угодно долго, повторно нажимать не нужно. В обычном режиме новый аккорд после
отпускания всех клавиш заменяет предыдущий на текущем шаге. Sticky сохраняет ранее
введённые ноты и добавляет новые, позволяя собрать аккорд несколькими нажатиями.
Shift + K/L заменяют старые сочетания выделения.
Запись Shift + R квантизирует начало к ближайшему шагу с учётом Swing. Любые
две ноты одного канала, попавшие в один шаг, занимают этот и следующий шаг;
при третьей средняя заменяется последней. На границе используется шаг 1.
Таблица конфликтов очищается после каждого прохода. Запись идёт в играющий паттерн.

Микротон и подъезд можно сочетать; они хранятся отдельно для MIDI-каналов 1–9.
Клавиши 1–8 и кнопки Pitch сразу изменяют соответствующий компонент выделенных
нот, сохраняя остальные свойства. Backtick сбрасывает их pitch, сохраняя артикуляцию.
Без выделения готовится пресет следующего ввода мышью/пэдом. Повторное нажатие
выключает компонент. Одновременно удерживаемые 1–4 и 5–8 применяются ко всем
вводимым нотам, пока клавиши зажаты. Без удержания новый шаг потребляет пресет;
до ввода он работает на прослушивании. Set pitch (Shift + backtick) сохраняет
пресет и наносит его кликом/протягиванием только на существующие ноты. Удержание
backtick + ЛКМ снимает pitch при клике/протягивании, не стирая сами ноты.
Подъезд: 25–35 центов, длительность 1/16 или 1/48 целой ноты ±30 мс. Диапазон
pitch bend ±2 полутона задаётся через RPN. На одном MIDI-канале bend действует
на все звучащие ноты; для аккорда используется настройка самой низкой ноты.
Колесо SMK с канала 1 направляется только на каналы с зажатыми клавишами и
складывается с микротоном/подъездом.
Во вкладке Microtones / Approaches редактируются центы и время перехода микротона
в мс, начало подъезда, случайное отклонение ± в центах, время (например `1/16`,
`1\128`, либо `120` мс), кривизна 0–100: вогнутая / линейная 50 / выпуклая.
Изменения относятся к следующим вводимым пресетам; записанные ячейки хранят свой звук.
Микротональные кнопки также доступны над сеткой.
Ctrl + backtick выключает Q/W/E/R/F, Select Mode, Drone, B/N/C, Mono текущего
канала, Step/Sticky/Record и Set pitch, сбрасывает pitch-пресеты. Gate View,
Audition, D и Hotkey Mode остаются как были; транспорт и уже записанные ноты не меняются.

Цветовой цикл пустых шагов непрерывен на всех 64 шагах. Ползунок PC empty-grid tint
во вкладке Interface меняет только слабую подкраску сетки на ПК; по умолчанию 8%.
Доступны Dark, Light, Legacy light и цвета всех банков каналов 10–16.
Звёздочка у пэда обозначает функцию; подсказка показывает назначение.

Shortcuts содержит физический код, латинское название клавиши, MIDI-контроллер,
канал и MIDI Learn. Для проверки второго банка выберите Gate knob, MIDI Learn,
поверните нужный ноб и нажмите Apply. Строка статуса показывает входящий CC и канал.
Close закрывает настройки без применения новых правок. Последняя вкладка запоминается
до закрытия программы. Экспорт/импорт настроек — `.settingsjson`; проектов — `.patternsjson`.

Channel outputs → Separate MIDI devices включает отдельные устройства для каналов
1–9. Первый канал и Clock/Start/Stop используют основной Sequence / audition output
во вкладке MIDI. Для 2–9 можно выбрать отдельные выходы; пустое поле использует
основной. Номера MIDI-каналов сохраняются. Ноты, дроны, audition, pitch bend и RPN
следуют этой маршрутизации; clock передаётся только в основной выход.

Подключения проверяются в фоне каждые 2 с. Исчезнувшие устройства и выходы с ошибкой
переоткрываются при доступности. Вход без сообщений и удерживаемых клавиш обновляется
после 120 с тишины, без остановки транспорта. Reconnect MIDI останавливает транспорт
и переоткрывает порты вручную. Ошибка обработки интерфейса больше не обрывает MIDI-цикл;
её подробности сохраняются рядом с настройками в `.meetstep.log`.
